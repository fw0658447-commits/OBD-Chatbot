# Trading Cockpit Product Spec

## Ziel

Multi-Asset Trading-Cockpit mit KI-Prognosen, Paper-Trading-Bot, Musterdepot, Risiko-Engine und spaeterer Broker-Anbindung.

## MVP v0.1

- Marktdaten
- Watchlist
- Chart-Grundlage
- Musterdepot-Placeholder

## MVP v0.2

- Indikatoren
- regelbasiertes KI-Scoring
- Long/Short/Neutral-Prognose

## MVP v0.3

- Paper-Bot
- Risiko-Engine
- Bot-Journal
- Stop-Loss/Take-Profit-Logik
